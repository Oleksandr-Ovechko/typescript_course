# Примеры одиннадцатого урока

Всё, что было на экране, — в готовом виде и с объяснениями. Каждый файл
исполняемый: он собирает свою песочницу в `/tmp/wl-pw-examples/`, запускает
Playwright и по ходу рассказывает, что произошло.

```bash
bash lessons/lesson-11/examples/01-running-and-filtering.sh   # запустить любой файл
cd /tmp/wl-pw-examples/running-and-filtering                  # песочница остаётся — ковыряйте
```

Ничего за пределами `/tmp` скрипты не трогают: `wl-e2e` и ваш рабочий
репозиторий в безопасности. Объяснение каждой темы — в
[конспекте урока](../README.md).

## Что нужно, чтобы запустить

Только установленный `wl-e2e`: Playwright берётся из его `node_modules`
симлинком — та же версия, что в проекте. Ставить ничего не нужно,
стенд и интернет не нужны.

Если `wl-e2e` лежит не в `~/work/wl-e2e`, укажите путь:

```bash
WL_E2E=/путь/к/wl-e2e bash lessons/lesson-11/examples/01-running-and-filtering.sh
```

Каждый прогон поднимает свой сервер на порту **4173** и гасит его после.
Если скрипт говорит, что порт занят, — где-то завис прошлый прогон:
`fuser -k 4173/tcp`.

## Порядок чтения

**01 → 02 → 03** — как тест запускается и чем управляется. Их можно
читать отдельно от остальных.

**04 → 05 → 07** — одна линия: что остаётся после падения, как это
читать, и почему у флейки-теста трейс «не тот». 07 без 04 не читается:
весь его смысл — в папке `-retry1`, которая появляется в 04.

**06** (видео) и **08** (Allure) стоят особняком. **09** — ответ на вопрос
с занятия; начинать с него стоит тем, у кого `getByRole` «не работает».

## Чего ждать от вывода

- **Время в скобках гуляет** от прогона к прогону. И порядок строк тоже:
  номера `1`, `2`, `3` у тестов раздаются по мере завершения, а тесты
  идут параллельно в двух воркерах.
- **Прогоны с упавшими тестами печатают `(код возврата: 1)`** — так
  и задумано: в песочнице один тест падает всегда (сервер отвечает 500
  на бронирование), а один — только на первой попытке. Сам скрипт при
  этом доходит до конца и завершается с кодом 0.
- **`06-video-contexts.sh`** печатает имя второго видео вида
  `page@<набор букв и цифр>.webm` — у вас набор будет другим.
- **`08-allure.sh`** без установленной Java печатает `ERROR: JAVA_HOME is
  not set` — это часть примера, а не поломка.
- **HTML-отчёт в браузере не открывается** — в примерах стоит
  `PLAYWRIGHT_HTML_OPEN=never`. Открыть его: `cd` в песочницу
  и `node_modules/.bin/playwright show-report`.
- **Окно трейса тоже не открывается.** Команда, чтобы открыть самим, —
  в шапке `05-trace-cli.sh`.

Весь набор подряд идёт около полутора минут:

```bash
for f in lessons/lesson-11/examples/0*.sh; do bash "$f"; done
```
