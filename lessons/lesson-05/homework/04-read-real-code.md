### 1. Гонка, которая не умеет проиграть

Откройте `helpers/monolith/forms/form-settings-page.ts`, строка 94:

```ts
await Promise.race([
  expect(saveChangesConfirm)
    .toBeVisible({ timeout: 30_000 })
    .catch(() => undefined),
  expect(listRow)
    .toBeVisible({ timeout: 30_000 })
    .catch(() => undefined),
]);
if (await saveChangesConfirm.isVisible().catch(() => false)) {
  await saveChangesConfirm.click();
}
await expect(listRow).toBeVisible({ timeout: 30_000 });
```

Хелпер сохраняет настройки формы. Иногда перед сохранением выскакивает
подтверждение «Save changes…», иногда нет — заранее неизвестно.

- **а.** Что именно ждёт этот `Promise.race`? Назовите оба события, которые
  с ним гоняются.
- **б.** Может ли этот `race` отказать — то есть уйти в `catch`? Ответ
  обоснуйте: посмотрите, что делает `.catch(() => undefined)` на каждой ветке.
- **в.** Что произойдёт, если **ни то, ни другое** не появится за тридцать
  секунд? Сколько времени займёт строка `await Promise.race([...])` и с каким
  результатом она закончится?
- **г.** Последняя строка хелпера снова ждёт `listRow` — те же тридцать секунд.
  Выглядит как дубль. Почему её нельзя убрать?
