# Домашка урока 5

До урока 6. Ответы присылать не нужно: у каждого задания есть «Готово,
когда», по нему и проверяйте себя. Хотите, чтобы посмотрели, — кидайте
в чат группы. Застряли — тоже в чат, с командой и её выводом.

| № | Файл | Что делаем | Готово, когда |
|---|------|-----------|---------------|
| 1 | [`01-predict-output.ts`](01-predict-output.ts) | Предсказать вывод девяти строк: замыкание, `var`/`let` в цикле, ссылки, копии, `this` | У каждой `// →` есть прогноз и «почему», файл запущен, расхождения объяснены |
| 2 | [`02-closure.ts`](02-closure.ts) | `makeMultiplier(factor)` и кошелёк `makeWallet(start)` на замыкании | Файл печатает восемь `true`, на вопрос в конце есть ответ |
| 3 | [`03-copy.ts`](03-copy.ts) | `withName` и `withCity`: новая копия, оригинал не тронут | Файл печатает восемь `true`, на вопрос в конце есть ответ |
| 4 | [`04-team.ts`](04-team.ts) | Пример `team` по шагам: порядок строк и откуда `this` | Порядок записан, на три вопроса есть ответы, каждый проверен запуском |

## Команды

```bash
node lessons/lesson-05/homework/01-predict-output.ts   # запустить файл задания
yarn typecheck:hw5                                     # проверить типы домашки
```

Файлы правьте прямо здесь, в `lessons/lesson-05/homework/`: команды
выше и `yarn typecheck:hw5` смотрят именно сюда.

## Про задание 1

Прогноз пишется **до** запуска. Совпало — хорошо. Не совпало — это самое
ценное место: допишите, почему так вышло.

## Про задания 2 и 3

В функциях стоят заглушки: с ними часть проверок печатает `false`.
Замените заглушки своим кодом, проверки внизу не трогайте.
`yarn typecheck:hw5` до выполнения ошибок не показывает: здесь сигнал —
`false` в выводе, а не красный `tsc`.

## Про задание 4

Это пример, который на занятии назван главным заданием на дом. Его можно
разбирать вместе с Claude Code: попросите объяснить, какая строка когда
выполняется и откуда берётся `this`. Но каждое объяснение проверьте сами —
вставьте `console.log`, поменяйте код, запустите. Если вывод не совпал
с объяснением — это и есть находка.
