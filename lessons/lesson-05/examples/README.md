# Примеры урока 5

Весь код, который был на экране, в готовом виде и с комментариями.
Читайте сверху вниз: запускайте каждый файл и сверяйте вывод со своим
прогнозом. Объяснение каждой темы — в [конспекте урока](../README.md).

```bash
node lessons/lesson-05/examples/01-closure.ts   # запустить любой файл
yarn typecheck                                  # проверить типы всех примеров
```

| Файл | Тема | О чём |
|------|------|-------|
| [`01-closure.ts`](01-closure.ts) | [Замыкание](../README.md#вложенные-функции-и-замыкание) | Вложенная функция, лексическое окружение, «помнит, где написана», счётчики, замыкание ничего не копирует, держит переменную, `var` и `let` в цикле |
| [`02-objects.ts`](02-objects.ts) | [Объекты](../README.md#объекты) | Литерал, короткая запись, `.` и `[]`, ключи — строки, вычисляемые свойства, `?.`, ссылка и `===`, поверхностная и глубокая копия |
| [`03-methods-and-this.ts`](03-methods-and-this.ts) | [Методы и `this`](../README.md#методы-объекта-и-this) | Метод и `this`, метод меняет объект, `?.()`, одна функция в двух объектах, `this:` — не параметр, метод у копии, оторванный метод, стрелка без своего `this` |
| [`04-asked-during-lesson.ts`](04-asked-during-lesson.ts) | [Сверх плана](../README.md#сверх-плана) | Магазин яблок, затенение против замыкания, новое свойство и `b?:`, `const` и объект, копия через `JSON` |

## Строки, которые не должны компилироваться

Они закомментированы с пометкой `// ❌ TS####`. Раскомментируйте любую
и запустите `yarn typecheck`: код ошибки должен совпасть с заявленным.
Потом закомментируйте обратно.
