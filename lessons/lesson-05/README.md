# Урок 5. Замыкание, объекты, `this`

Пока здесь план и словарь, полный конспект появится после занятия.

Тем намеренно больше, чем влезет в одно занятие. Идём по порядку, а что
не успеем, продолжим в уроке 6. Перед занятием полезно перечитать
[где видно имя](../lesson-04/README.md#где-видно-имя) из урока 4.

## План

1. **Повторение: где видно имя** — блок `{}` и затенение, `var` в цикле,
   поднятие и мёртвая зона.
2. **Вложенные функции и замыкание** — лексическое окружение, поиск имени
   наружу, функция помнит место, где её написали.
3. **Объекты** — литерал и свойства, обращение через `.` и `[]`, вычисляемые
   свойства, опциональная цепочка `?.`, ссылка, копирование.
4. **Методы объекта и `this`** — метод меняет свой объект, необязательный
   метод, `this` из места вызова, метод у копии, потерянный `this`, стрелка
   без своего `this`, `call`, `apply`, `bind`.

После блоков — короткие тесты, ссылку ведущий даст на занятии.

## Словарь терминов

| Термин | Что значит |
|--------|------------|
| **лексическое окружение** (lexical environment) | место, где лежат переменные одного вызова функции. У него есть ссылка на внешнее окружение — там, где функция написана |
| **замыкание** (closure) | функция вместе с окружением места, где её создали. Пока жива функция, живы и переменные этого окружения |
| **контекст** (`this`) | объект, на который указывает `this` внутри вызова: то, что стоит слева от точки. В функции не хранится, определяется при каждом вызове |
| **вычисляемое свойство** (computed property) | свойство, ключ которого записан в `[ ]` и вычисляется при создании объекта: `{ [key]: value }` |
| **опциональная цепочка** (optional chaining) | `?.`: читает дальше, только если слева не `null` и не `undefined`. Иначе результат — `undefined` |
| **ссылка** (reference) | то, что лежит в переменной вместо самого объекта. Присваивание копирует ссылку, а объект остаётся один |
| **поверхностная копия** (shallow copy) | новый объект, в который скопирован только верхний уровень: `{ ...obj }`. Вложенные объекты остаются общими |
