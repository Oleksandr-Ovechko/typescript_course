есть «Готово, когда», по нему и проверяйте себя. Хотите, чтобы посмотрели, —
кидайте в чат группы. Застряли — тоже в чат, с командой и её выводом.

## Команды

```bash
node lessons/lesson-04/homework/01-predict-output.ts   # запустить файл задания
yarn typecheck:hw4                                     # проверить типы домашки
```

Файлы правьте прямо здесь, в `lessons/lesson-04/homework/`: команды
выше и `yarn typecheck:hw4` смотрят именно сюда.

## Про задание 1

Прогноз пишется **до** запуска. Совпало — хорошо. Не совпало — это самое
ценное место: допишите, почему так вышло. Строки без номера (`внутри 1`)
тоже печатаются — где именно они окажутся, тоже часть прогноза.

## Про задания 2–4

В каждой функции стоит заглушка `return NaN`: с ней проверки печатают
`false`. Замените заглушку своим кодом, проверки внизу не трогайте.

До выполнения `yarn typecheck:hw4` показывает **одну** ошибку — `TS7006`
в задании 3. Это часть задания, а не сбой: TypeScript не знает, какого
типа `n`, пока у `action` нет типа. Опишете тип — ошибка исчезнет.

Если задание 4 упало с `RangeError: Maximum call stack size exceeded`,
компьютер ни при чём: функция вызывает себя без конца. Ищите, какое `n`
проскакивает мимо базового случая.

## 5. Необязательное: Claude Code

Откройте `claude` в папке курса и попросите: «объясни разницу между `...`
в параметрах функции и `...` при вызове на трёх своих примерах». Каждый
пример запустите сами (`node -e "…"` или в `playground/`) и сверьте вывод
с объяснением. Если не совпало — это и есть находка.
