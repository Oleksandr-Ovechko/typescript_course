```bash

node lessons/lesson-04/homework/01-predict-output.ts      # запустить конкретный файл
```

## Важное про задание 1

Прогноз пишется **до** запуска, и задание не засчитывается без объяснения.
Цель не в том, чтобы угадать строку, а в том, чтобы поймать место, где ваша
модель расходится с реальностью. Совпало — хорошо; не совпало — самое ценное
место, припишите почему.

## Важное про задание 2

До починки `yarn typecheck:hw4` показывает **одну** ошибку — это часть
задания, а не сбой. Остальные три бага компилятор считает законным кодом:
сигнал о них — только `❌` при запуске. Код проверок трогать нельзя: чинить
нужно сами функции.
