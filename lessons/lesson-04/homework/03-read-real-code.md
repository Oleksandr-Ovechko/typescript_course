# Задание 3 — прочитать настоящий код

Найдите в `wl-e2e` место, где значение со страницы превращается в число.
Подсказка — команда из корня `wl-e2e`:

```bash
git grep -nE "(Number|parseFloat|parseInt)\((await |\(await )?[a-zA-Z.]*(textContent|innerText|inputValue)" origin/draft -- 'helpers/*.ts'
```

Выберите **одно** место и ответьте со ссылкой `файл:строка`:

1. Какой функцией строка превращается в число — `Number`, `parseFloat` или `parseInt`?
   Подходит ли она для дробных сумм?
2. Что окажется в переменной, если на странице **пустая строка**? Проверьте
   догадку в `node`, подставив `''` вместо значения со страницы.
3. Что будет дальше в коде с этим значением: проверка упадёт, пройдёт
   или молча сравнит не то?
