node lessons/lesson-04/examples/03-numbers.ts   # запустить любой файл
yarn typecheck                                  # проверить типы всех примеров

## Чего ждать от вывода

Два файла ведут себя не так, как читаются:

- **`05-scope-and-copies.ts`** — шесть строк про цикл появятся **в самом конце**,
  после всего остального. `setTimeout` откладывает вызов до конца синхронного
  кода. Это и есть тема пункта, а не сбой.
- **`04-strings.ts`** — пятая строка печатает `�`. Так и должно быть: `slice`
  разрезал эмодзи пополам.

## Строки, которые не должны компилироваться

Их шесть, все закомментированы с пометкой `// ❌ TS####`. Расскомментируйте
любую и запустите `yarn typecheck` — код ошибки должен совпасть с заявленным.

Ещё пять мест помечены `@ts-expect-error`: там ошибка ожидается, и
`yarn typecheck` упадёт, если она вдруг **перестанет** появляться.
