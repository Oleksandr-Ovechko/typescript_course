# Примеры урока 4

Весь код, который был на экране, в готовом виде и с комментариями.
Читайте сверху вниз: запускайте каждый файл и сверяйте вывод со своим
прогнозом. Объяснение каждой темы — в [конспекте урока](../README.md).

```bash
node lessons/lesson-04/examples/03-functions-as-values.ts   # запустить любой файл
yarn typecheck                                              # проверить типы всех примеров
```

| Файл | Тема | О чём |
|------|------|-------|
| [`01-writing-functions.ts`](01-writing-functions.ts) | [Как записать функцию](../README.md#как-записать-функцию) | `return` и `undefined`, `: void`, объявление, выражение и стрелка, короткое и полное тело, IIFE и что лежит в переменной после неё |
| [`02-parameters.ts`](02-parameters.ts) | [Параметры](../README.md#параметры) | Умолчание с `undefined`, `''`, `0` и `null`, недостающий аргумент, `arguments` и стрелка, остаточные параметры, спред, длина против содержимого |
| [`03-functions-as-values.ts`](03-functions-as-values.ts) | [Функция — это значение](../README.md#функция--это-значение) | Без скобок — функция, тип функции против самой функции, колбэк, вызов вместо передачи, рекурсия, имя у выражения |
| [`04-scope.ts`](04-scope.ts) | [Где видно имя](../README.md#где-видно-имя) | Блок и затенение, `var` в блоке, в цикле и в функции, поднятие, мёртвая зона и два `ReferenceError`, глобальный объект и модули |
| [`05-asked-during-lesson.ts`](05-asked-during-lesson.ts) | [Сверх плана](../README.md#сверх-плана) | `+` против `${}`, `console.log` с `...`, что делает `map`, колбэк по умолчанию |

## Строки, которые не должны компилироваться

Они закомментированы с пометкой `// ❌ TS####`. Раскомментируйте любую
и запустите `yarn typecheck`: код ошибки должен совпасть с заявленным.
Потом закомментируйте обратно.
