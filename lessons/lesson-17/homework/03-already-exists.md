# Задание 3. «Уже есть» — но такой ли?

В `helpers/` десяток функций вида `create…IfNotExists` и `ensure…`.
Одни находят сущность по имени и сразу возвращаются, другие ещё и
проверяют, что настройки те, что нужны тесту. Разница — правило T1
(`RULES.md`), и её не ловит ни одна проверка гейта.

## Что сделать

1. Найдите функции:

   ```bash
   git grep -n "export async function \w*IfNotExists" -- helpers
   ```

2. Выберите **одну** (не `createAppointmentIfNotExists` — она разобрана
   на уроке) и прочитайте её целиком, вместе с докблоком.
3. Найдите один спек, который её вызывает:
   `git grep -n "<имяФункции>" -- projects`.
