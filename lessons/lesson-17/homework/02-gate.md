# Задание 2. `yarn gate` на своей ветке

## Что сделать

1. Перейдите на свою рабочую ветку (с последним PR или текущей задачей).
2. Из корня `wl-e2e`:

   ```bash
   yarn gate
   ```

   Идёт несколько минут. В конце — строка вида
   `✗ gate — N of 13 step(s) failed: …` или зелёный итог.
3. Для каждого красного шага узнайте, ваш ли он: переключитесь на базовую
   ветку своего PR (`draft` или `test-generation`), `git pull`, и
   запустите только этот шаг с теми же флагами, что в гейте:
   `yarn check:clusters --strict` (у линтера —
   `yarn lint --pass-on-unpruned-suppressions`). Без `--strict` проверка
   только предупреждает и всегда завершается с кодом 0. Красный и там —
   сломан не вами.
