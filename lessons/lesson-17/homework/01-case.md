# Задание 1. Свой кейс на `staging-genN`

Нужно: архив `.secure` от ведущего (никуда не пересылать) и ветка
`test-generation` — файлы окружений `staging-gen1…8` есть **только на ней**,
на `draft` их нет.

## Что сделать

1. В своём `wl-e2e`:

   ```bash
   git status                      # незакоммиченное — закоммитьте или git stash
   git fetch origin
   git switch test-generation
   git pull
   yarn install
   ```

2. Распакуйте `.secure` в `projects/monolith/config/` (или в `config/`
   того проекта, где ваш кейс). `git status` после этого должен молчать:
   `.secure` в `.gitignore`.
3. Выберите **свой** кейс — который вы писали или валидировали — и
   окружение `staging-genN`, на котором он сгенерирован.
4. Проверьте окружение, ничего не запуская (из корня):

   ```bash
   yarn check:env-ready --env=staging-genN
   ```

5. Запустите кейс (из папки проекта):

   ```bash
   yarn case C<номер> --env=staging-genN
   ```
