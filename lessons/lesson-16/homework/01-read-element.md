# Задание 1. Прочитать элемент в консоли

Откройте любую страницу WL, с которой работаете (BO, CWA, виджет) —
или страницу примеров урока: `bash lessons/lesson-16/examples/03-nodes-and-text.sh`,
потом `cd /tmp/wl-dom-examples/nodes-and-text && node site/server.mjs`,
http://localhost:4177.

F12 → Console. Ничего не сохраняйте и не отправляйте — только читайте.

## Что сделать

1. Выберите **три** элемента: заголовок или подпись, кнопку, поле ввода.
   Найдите каждый через `document.querySelector(…)` — селектор подберите
   сами (вкладка Elements, правый клик → Copy → Copy selector — можно,
   но потом упростите).
2. Для каждого прочитайте и запишите в таблицу:
   - `JSON.stringify(el.textContent)` — `JSON.stringify` покажет переносы и пробелы;
   - `JSON.stringify(el.innerText)`;
   - два атрибута — `el.getAttributeNames()` подскажет, какие есть.
3. Для поля ввода — ещё `el.value` и `el.getAttribute('value')`.
   Впишите в поле что-нибудь руками — **не сохраняя форму** — и
   прочитайте оба ещё раз.
