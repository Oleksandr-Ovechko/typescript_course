# Домашнее задание к уроку 18

Сеть и `docker compose` на занятии не успели — они здесь, пошагово,
на приложении [`runlog`](../runlog/). Все команды — из папки
`lessons/lesson-18/runlog` (сначала `git pull` в курсе). Нужен Docker
и образы `node:24-alpine`, `postgres:18-alpine`. Ответы — в файлах
заданий, в разделе «Ответ».

| № | Файл | Что делаем | Готово, когда |
|---|------|-----------|---------------|
| 1 | [`01-network.md`](01-network.md) | Приложение и Postgres в двух контейнерах: `localhost`, имя, своя сеть, данные в томе | Записан вывод каждого шага; на три вопроса — ответ своими словами |
| 2 | [`02-compose.md`](02-compose.md) | То же одним `compose.yaml`: гонка при старте, `healthcheck`, `down` и `down -v` | Вывод `docker compose ps` до и после `healthcheck`; ответ, где данные после `down` и после `down -v` |
| 3 | [`03-wl-e2e.md`](03-wl-e2e.md) | *По желанию.* Свой кейс в контейнере `wl-e2e` | Сколько собирался образ, вывод `--list` и итог прогона |

Застряли — готовый прогон каждого шага: [`05-network.sh`](../examples/05-network.sh),
[`06-compose.sh`](../examples/06-compose.sh). Но сначала руками: смысл
в том, чтобы увидеть ошибки самим.

Windows: `curl.exe` вместо `curl`, команды — в одну строку, файл
`compose.yaml` — создать в VS Code.
