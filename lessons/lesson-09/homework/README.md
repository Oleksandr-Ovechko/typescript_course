## 2. Устроить себе конфликт и разрешить его

Собрать всё самому, **не подглядывая в пример** (подглядеть можно потом, чтобы
сверить): свою песочницу, «сервер» через `git init --bare`, клон-«коллегу»,
по правке с каждой стороны в одну и ту же строку.

Разрешить конфликт **через VS Code Merge Editor**, а не руками в терминале.

Прислать:

```bash
git log --oneline --graph --all --decorate
```

В графе должно быть видно, как две линии сходятся в коммит слияния. Заодно
проверьте себя: `git cat-file -p HEAD | grep '^parent'` — сколько строк
и почему?

**Дополнительно, если пойдёт легко:** повторите то же самое, но правки сделайте
в строках, между которыми есть одна нетронутая строка. Объясните результат.

## 3. Пройти путь PR в песочнице

Смоделировать рабочий процесс целиком, без GitHub:

1. Репозиторий с двумя разошедшимися ветками: `draft` и `experiment`
   (по десятку коммитов в каждой после общего предка).
2. На `experiment` — «починенный тест», отдельный файл.
3. Попробовать перенести его на `draft` через `cherry-pick` и получить
   конфликт. Отменить.
4. Сделать как надо: `git worktree add -b AUT-1234-C99999-slug ../pr-wt draft`,
   перенести файл через `git -C ... show ветка:путь > путь`, закоммитить.
5. Убрать за собой: `git worktree remove ../pr-wt`.

Прислать вывод `git diff --stat draft...HEAD` из рабочего дерева PR-ветки.
**В нём должен быть ровно один файл** — если больше, разберитесь, откуда
взялись остальные.

## 5. Замерить расхождение в `wl-e2e`

```bash
cd /home/alex/work/wl-e2e
git fetch origin draft
git rev-list --left-right --count origin/draft...HEAD
```

Прислать два числа и объяснить словами, что означает каждое. Числа у всех
будут немного разные — это нормально, они меняются каждый день.

Второй вопрос к этому же заданию: **почему левое число иногда растёт, а потом
уменьшается, а правое только растёт?**
