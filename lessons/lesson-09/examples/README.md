# Примеры девятого урока

Всё, что было на экране, — в готовом виде и с объяснениями. Каждый файл
исполняемый: он заводит в `/tmp/wl-git-examples/` свои репозитории (ваш,
«сервер», иногда «коллегу»), выполняет команды и по ходу рассказывает,
что произошло.

```bash
bash lessons/lesson-09/examples/03-conflict.sh   # запустить любой файл
cd /tmp/wl-git-examples/l9-conflict/sandbox      # песочница остаётся — ковыряйте
```

Ничего за пределами `/tmp` скрипты не трогают, интернет им не нужен.
Объяснение каждой темы — в [конспекте урока](../README.md).

## Порядок чтения

**01 → 02 → 03** идут лесенкой и читаются подряд: во втором нужно понимать, что
такое `origin/main` из первого, в третьем — что такое отклонённый push
из второго.

**04 → 05** — рабочий процесс. Это то, что вы будете делать руками каждую
неделю, и 05 без 04 не читается.

**06** — отдельно, справочно: `rebase` вам применять не придётся, но слово
встретится в первый же день.

## Если что-то пошло не так

Скрипты используют `set -e`: при первой же ошибке они останавливаются, и вы
видите, на каком шаге. Песочница при этом остаётся на диске — можно зайти
в неё и посмотреть состояние своими глазами:

```bash
cd /tmp/wl-git-examples/l9-conflict/sandbox
git status
git log --oneline --graph --all --decorate
```

Начать заново — просто запустить скрипт ещё раз: он сносит свою папку сам.
