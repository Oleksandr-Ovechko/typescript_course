# Примеры урока 2

Весь код, который был на экране, в готовом виде и с комментариями.
Читайте сверху вниз: запускайте каждый файл и сверяйте вывод со своим
прогнозом. Объяснение каждой темы — в [конспекте урока](../README.md).

```bash
node lessons/lesson-02/examples/03-coercion.ts   # запустить любой файл
yarn typecheck                                   # проверить типы всех примеров
```

## Строки, которые не должны компилироваться

Они закомментированы с пометкой `// ❌ TS####`. Раскомментируйте любую
и запустите `yarn typecheck`: код ошибки должен совпасть с заявленным.
Потом закомментируйте обратно.
