когда», по нему и проверяйте себя. Если застряли, пишите в чат группы
и прикладывайте команду с её выводом.

## Команды

```bash
node lessons/lesson-02/homework/01-predict-output.ts   # запустить файл задания
yarn typecheck:hw2                                     # проверить типы домашки
```

Файлы заданий 1 и 2 правьте прямо здесь, в `lessons/lesson-02/homework/`:
команды выше и `yarn typecheck:hw2` смотрят именно сюда.

## Про задание 1

Прогноз пишется **до** запуска. Совпало — хорошо. Не совпало — это самое
ценное место: допишите, почему так вышло.

## Про задание 2

До починки `yarn typecheck:hw2` показывает **одну** ошибку. Это часть
задания, а не сбой. Остальные три ошибки TypeScript считает законным
кодом, и сигнал о них — только `false` при запуске. Проверки внизу файла
не трогайте.

## 4. Необязательное: Claude Code

Откройте `claude` в папке курса и попросите: «найди в материалах урока 2
три места, где строку превращают в число, и скажи, каким способом».
Откройте каждое место сами и убедитесь, что оно существует и Claude его
не выдумал.
