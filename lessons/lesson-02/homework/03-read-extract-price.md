# Задание 3 — прочитать настоящий хелпер

Так в рабочем проекте на Playwright достают цену со страницы. Это
**хелпер** — функция, которую вызывают тесты:

```ts
export async function extractPrice(locator: Locator): Promise<number> {
  const text = await locator.evaluate((el) => el.getAttribute('data-amount') || el.textContent || '');
  return parseFloat(text.replace(/[^0-9.]/g, ''));
}
```

Первая строка — объявление функции. Как такие пишутся, будет в уроках 3
и 11, сейчас читать её не нужно. Остальное — всё из урока 2.
Разбор по частям есть в конспекте:
[«Всё вместе: как проект достаёт цену»](../README.md#всё-вместе-как-проект-достаёт-цену).

Ответьте на вопросы:

1. Вторая строка: что окажется в `text`, если у элемента **нет**
   атрибута `data-amount`, а текст — `$19.99`? А если нет ни атрибута,
   ни текста? Какое правило `||` здесь работает?
2. Что вернёт функция, если в ячейке написано `$19.99`? `Free`? Если
   ячейка пустая?
3. Почему в последней строке стоит `parseFloat`, а не `parseInt`?
4. *Со звёздочкой.* Что вернёт функция для цены в европейской записи
   `1.234,56 €`? Совпадает ли это с тем, что видит человек?

*Готово, когда* у каждого ответа есть проверка запуском. Для этого
