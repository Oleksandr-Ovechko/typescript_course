# Домашка урока 6

До урока 7. Ответы присылать не нужно: у каждого задания есть «Готово,
когда», по нему и проверяйте себя. Хотите, чтобы посмотрели, — кидайте
в чат группы. Застряли — тоже в чат, с командой и её выводом.

| № | Файл | Что делаем | Готово, когда |
|---|------|-----------|---------------|
| 1 | [`01-predict-output.ts`](01-predict-output.ts) | Предсказать вывод восьми строк: `call` и `bind` поверх `bind`, стрелка в методе, деструктуризация с умолчаниями, `??=` и `\|\|=`, `for...in` по массиву, `try` снаружи и внутри цикла, `throw` строки | У каждой `// →` есть прогноз и «почему», файл запущен, расхождения объяснены |
| 2 | [`02-options-object.ts`](02-options-object.ts) | Функция с тремя параметрами → функция с одним объектом-параметром и умолчаниями | Файл печатает восемь `true`, на вопрос в конце есть ответ |
| 3 | [`03-prices.ts`](03-prices.ts) | Сумма, самый дорогой напиток и список «не дороже» — через `Object.entries` | Файл печатает восемь `true`, на вопрос в конце есть ответ |
| 4 | [`04-errors.ts`](04-errors.ts) | Функция бросает ошибку на плохих данных, подсчёт ловит её в цикле и идёт дальше | Файл печатает восемь `true`, на вопрос в конце есть ответ, проверенный запуском |

## Команды

```bash
node lessons/lesson-06/homework/01-predict-output.ts   # запустить файл задания
yarn typecheck:hw6                                     # проверить типы домашки
```

Файлы правьте прямо здесь, в `lessons/lesson-06/homework/`: команды
выше и `yarn typecheck:hw6` смотрят именно сюда.

## Про задание 1

Прогноз пишется **до** запуска. Совпало — хорошо. Не совпало — это самое
ценное место: допишите, почему так вышло.

## Про задания 2–4

В функциях стоят заглушки: с ними часть проверок печатает `false`.
Замените заглушки своим кодом, проверки внизу не трогайте.
`yarn typecheck:hw6` до выполнения ошибок не показывает: здесь сигнал —
`false` в выводе, а не красный `tsc`.

Можно разбирать вместе с Claude Code, но каждое объяснение проверяйте
сами: вставьте `console.log`, поменяйте код, запустите.
