# Урок 6. `call`, `apply`, `bind`, деструктуризация, обход объекта, ошибки

Пока здесь план и словарь, полный конспект появится после занятия.

Начнём с того, что не успели в уроке 5. Перед занятием полезно перечитать
[методы объекта и `this`](../lesson-05/README.md#методы-объекта-и-this)
из урока 5. Последний блок — запас: что не успеем, пройдём в уроке про

## План

1. **Повторение урока 5** — замыкание, ссылка, `this` на одном экране.
2. **`call`, `apply`, `bind`** — метод, отданный колбэком, теряет `this`;
   как задать `this` вручную и как сделать функцию с прибитым `this`.
3. **Деструктуризация** — коротко: объект по имени, массив по позиции,
   умолчания, остаток, шаблон в параметрах функции.
4. **Обход объекта** — `for...in`, `Object.keys`, `Object.values`,
   `Object.entries`; `??=` и `||=`.
5. **Запас: ошибки** — `try`, `catch`, `finally`, `throw new Error`,
   куда летит ошибка.

После блока 2 — короткий тест по объектам и `this`, ссылку ведущий даст
на занятии.

## Словарь терминов

| Термин | Что значит |
|--------|------------|
| **привязанная функция** (bound function) | функция, которую вернул `bind`: у неё `this` задан раз и навсегда, как её ни вызывай |
| **деструктуризация** (destructuring) | запись, которая раскладывает объект или массив по отдельным переменным: `const { item } = order`, `const [first] = list`. У объекта берут по имени, у массива — по позиции |
| **логическое присваивание** | `??=`, `\|\|=`, `&&=`: присвоить, только если проверка `??`, `\|\|` или `&&` слева пропускает дальше. `a ??= b` записывает `b`, только если `a` — `null` или `undefined` |
| **бросить ошибку** (throw) | оборвать выполнение и отправить наверх объект ошибки с сообщением. Строки после места броска не выполняются, пока ошибку не поймает `try`/`catch` |

Знакомые слова: **замыкание**, **ссылка**, **контекст** (`this`),
**поверхностная копия** — [словарь урока 5](../lesson-05/README.md#словарь-терминов);
**остаточные параметры**, **значение по умолчанию** — урок 4.
