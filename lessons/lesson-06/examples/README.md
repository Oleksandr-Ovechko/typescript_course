## Строки, которые не должны компилироваться

Они закомментированы с пометкой `// ❌ TS####`. Раскомментируйте любую
и запустите `yarn typecheck`: код ошибки должен совпасть с заявленным.
Потом закомментируйте обратно.

## Строка, которая компилируется, но падает

`greetLater()` — метод без точки — TypeScript пропускает, а `node` падает
с `TypeError`. В `01` её нет: она уронила бы весь файл. В `04` она стоит
внутри `try` — там видно и саму ошибку, и то, что файл после неё живёт.
