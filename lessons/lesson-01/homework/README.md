# Домашка урока 1

До урока 2. Задания 1 и 2 — обязательные: урок 2 начнётся с того, что
у всех работают `node` и `yarn typecheck`. Ответы присылать не нужно —
у каждого задания есть «Готово, когда», по нему проверяйте себя сами.
Застряли — в чат группы, с командой и её выводом.

## 1. Рабочее место

1. Поставить Claude Code **в терминале** (не только десктоп) —
   [quickstart](https://code.claude.com/docs/en/quickstart).
2. Поставить репозиторий курса — раздел «Установка» в
   [`README.md`](../../../README.md) курса.

*Готово, когда* в терминале, в корне курса:

```bash
claude --version     # номер версии
node --version       # v25.9.0
yarn typecheck       # последняя строка — Done in …
```

## 2. Устройство проекта своими руками

Пройти раздел [«Как устроен проект на JavaScript»](../README.md#как-устроен-проект-на-javascript)
конспекта — каждую команду у себя. Потом ответить себе на четыре вопроса:

1. Какая версия Node нужна курсу и в каком файле это записано?
2. Какая у курса зависимость и что значит `^` перед её версией?
3. Где записана **точная** версия, которая у вас стоит, и какая она?
4. Что именно запускает `yarn typecheck`? Где вы это увидели — и в выводе,
   и в файле?

*Готово, когда* на каждый вопрос есть ответ и место, где вы его
проверили: файл или вывод команды.

## 3. Строка состояния

В терминале, в папке курса, запустить `claude` и набрать `/statusline`,
а дальше — словами: «покажи модель, папку и сколько занято контекста».

*Готово, когда* внизу окна видно, сколько процентов контекста занято.

## 4. Claude как репетитор — и проверка Claude

1. `/output-style` → `Explanatory`.
2. Попросить: «задай мне пять вопросов по `lessons/lesson-01/README.md`
   и проверь мои ответы».
3. Выбрать одно утверждение Claude из этого разговора и проверить его
   сами — по конспекту, по документации или запуском.

*Готово, когда* вы можете сказать, на каком вопросе он вас поправил,
и что вы проверили сами — прав ли был он.

## Необязательное. Первый файл на TypeScript

Пройти раздел [«Первый файл на TypeScript»](../README.md#первый-файл-на-typescript)
в своём файле `playground/lesson-01/first.ts` (эту папку перед уроками
никто не перезаписывает). Три имени с типами — номер кейса, число
попыток, таймаут в миллисекундах — и один `console.log` всех трёх;
последней строкой — `export {};` (зачем — раздел про `TS2451`
в `README.md` курса). Потом нарочно испортить один тип.

*Готово, когда* `node playground/lesson-01/first.ts` печатает три
значения, `yarn typecheck` показывает `TS2322` на вашей строке, а после
исправления — `Done`.
