## Часть 1. Знакомство с проектом wl-e2e (~35 мин)

| Что | Зачем |
|-----|-------|
| `CLAUDE.md` в корне и в каждом проекте | входная точка и для человека, и для Клода; читается всегда, переживает компактизацию контекста |
| `.claude/commands/` | скиллы — повторяемые действия через `/команду` |
| `.claude/knowledge/page-facts/` | база знаний о неочевидном поведении страниц; `INDEX.md` — краткая сводка, по ней Клод ищет нужный файл |
| `.claude/workflows/` | рой агентов с заданными фазами, моделями и промптами (позже) |

| `RULES.md` | краткая выжимка правил написания тестов |
| `UI-PATTERNS.md` | развёрнутый справочник: архитектура, хелперы, работа с монолитом |
| ESLint | те же правила, но проверяемые механически |
| `.nvmrc` | фиксирует версию Node на проекте |
| MCP-серверы | внешние инструменты, к которым обращается Клод |

**Архитектура тестов.** Общие хелперы в `helpers/` **заморожены**: менять существующее
нельзя, добавлять новое — можно. Нужно изменить поведение — копируете хелпер в свой
`C123456.helpers.ts` и правите там. Дубликаты — осознанно принятый риск.

**Правила проекта важнее существующих примеров.** Старые тесты написаны в старом стиле;
ориентируемся на `RULES.md`, а не на соседний файл.

**Три проекта:** `monolith`, `widgets`, `explorer` (устарел). Тесты запускаются из папки
проекта, не из корня. У каждого свои конфиги Playwright под окружения; у
`regression-run` разрешены retries, у `e2e-tests` — нет, потому что они создают
сущности с soft delete.

**Ветки:** `main` (устарела) · `draft` (основная, туда PR) · `autonomous-test-gen-experiment`
(сервер генерации, опережает draft на ~600 коммитов, не мержится напрямую).

## Часть 2. TypeScript

- TS — надстройка над JS; валидный JS остаётся валидным TS
- Node как рантайм: движок V8 + файлы, сеть, процессы
- Транспиляция TS → JS через `tsc`; `dist/`, source maps и зачем они при отладке
- `tsconfig.json`: `target`, `module`, `moduleResolution`, `strict`, `noEmit`, `rootDir`, `outDir`
- Статическая типизация против динамической; синтаксис `имя: тип`
- Примитивы: `number`, `string`, `boolean`, `bigint`, `undefined`, `null`, `symbol`
- Всё остальное — объекты; сравнение **по ссылке**, ключи всегда строки
- Массивы: `number[]`, `Array<number>`, дырявые массивы, `push` / `pop`, `Array.isArray`
- Функции: объявление, параметры, тип возврата, `noImplicitAny`
- `Map` и `Set`, их методы, типизация
- `any` / `unknown` / `never`
- `enum` и tuple

## ⚠️ Ошибки этого урока

Шесть штук — разобраны в [уроке 2](../lesson-02/README.md#работа-над-ошибками-первого-урока),
с кодом, который можно запустить: [`examples/00-errata.ts`](../lesson-02/examples/00-errata.ts).

Коротко: примитивов **7**, а не 8/4 · `strict` в tsconfig ≠ `'use strict'` ·
`tsc` не ставим глобально · Map и Set — **не** массивы · `enum` у нас **не** используют ·
forward declaration функций в JS **нет**.

И главное, что не прозвучало: **типов в рантайме нет**, поэтому тест может
запуститься с ошибкой типов.
