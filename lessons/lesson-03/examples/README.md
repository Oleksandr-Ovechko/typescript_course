# Примеры урока 3

Весь код, который был на экране, в готовом виде и с комментариями.
Читайте сверху вниз: запускайте каждый файл и сверяйте вывод со своим
прогнозом. Объяснение каждой темы — в [конспекте урока](../README.md).

```bash
node lessons/lesson-03/examples/04-nullish.ts   # запустить любой файл
yarn typecheck                                  # проверить типы всех примеров
```

| Файл | Тема | О чём |
|------|------|-------|
| [`01-comparisons.ts`](01-comparisons.ts) | [Сравнения](../README.md#сравнения) | `<`, `>`, `!==`, строки по кодам символов, `'10' < '9'`, `'0'` истинное и `0 == '0'` |
| [`02-logic.ts`](02-logic.ts) | [Логика](../README.md#логика---) | `&&`, `\|\|`, `!`, порядок, сокращённое вычисление, ноль в `\|\|`, `30_000` |
| [`03-branches.ts`](03-branches.ts) | [Ветвления](../README.md#ветвления) | `if`/`else if` и порядок условий, тернарник и цепочка, `switch` с `break` и без |
| [`04-nullish.ts`](04-nullish.ts) | [`??`](../README.md#--запасное-значение-только-если-значения-нет) | `??` против `\|\|`, тип `string \| null`, цепочка `??` |
| [`05-arrays-and-loops.ts`](05-arrays-and-loops.ts) | [Массив и циклы](../README.md#массив-и-циклы) | Край массива, `for` и `<=`, `break` и потолок, `while`, `for...of`, `continue`, `for...in` |
| [`06-asked-during-lesson.ts`](06-asked-during-lesson.ts) | [Сверх плана](../README.md#сверх-плана) | `pop`, `do...while`, `for (;;)`, `sort` и что возвращает его колбэк, тип «или» |

## Строки, которые не должны компилироваться

Они закомментированы с пометкой `// ❌ TS####`. Раскомментируйте любую
и запустите `yarn typecheck`: код ошибки должен совпасть с заявленным.
Потом закомментируйте обратно.
