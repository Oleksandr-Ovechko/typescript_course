```bash
yarn typecheck:hw3                                  # проверить типы домашки
node lessons/lesson-03/homework/01-callbacks.ts      # запустить конкретный файл
```

## Важное про задание 2

Прогноз пишется **до** запуска. Задание не на угадывание строки, а на то, чтобы
поймать место, где ваша модель исполнения расходится с реальностью. Совпало —
хорошо; не совпало — самое ценное место, припишите почему.
