# Домашка урока 3

До урока 4. Ответы присылать не нужно: у каждого задания есть «Готово,
когда», по нему и проверяйте себя. Хотите, чтобы посмотрели, — кидайте
в чат группы. Застряли — тоже в чат, с командой и её выводом.

| № | Файл | Что делаем | Готово, когда |
|---|------|-----------|---------------|
| 1 | [`01-predict-output.ts`](01-predict-output.ts) | Предсказать вывод двенадцати строк по всем темам урока | У каждой `// →` есть прогноз и «почему», файл запущен, расхождения объяснены |
| 2 | [`02-four-bugs.ts`](02-four-bugs.ts) | Починить четыре куска кода, в каждом одна ошибка | Файл печатает четыре `true`, `yarn typecheck:hw3` без ошибок; есть ответ, какую ошибку нашёл TypeScript и почему только её |
| 3 | [`03-poll-with-cap.ts`](03-poll-with-cap.ts) | Написать повтор с потолком: опрашивать статус, пока не `done`, но не больше N раз | Вывод совпадает с указанным в файле при обоих потолках, на вопрос в конце есть ответ |
| 4 | ниже | *Необязательное.* Claude Code как собеседник по `??` | Три своих примера, каждый проверен запуском |

## Команды

```bash
node lessons/lesson-03/homework/01-predict-output.ts   # запустить файл задания
yarn typecheck:hw3                                     # проверить типы домашки
```

Файлы правьте прямо здесь, в `lessons/lesson-03/homework/`: команды
выше и `yarn typecheck:hw3` смотрят именно сюда.

## Про задание 1

Прогноз пишется **до** запуска. Совпало — хорошо. Не совпало — это самое
ценное место: допишите, почему так вышло.

## Про задание 2

До починки `yarn typecheck:hw3` показывает **одну** ошибку. Это часть
задания, а не сбой. Остальные три ошибки TypeScript считает законным
кодом, и сигнал о них — только `false` при запуске. Проверки внизу файла
не трогайте.

## Про задание 3

Цикл пишется с нуля — в файле только данные и потолок. Если вывод
не совпадает, добавьте `console.log` внутрь цикла и посмотрите, на каком
проходе всё пошло не так.

## 4. Необязательное: Claude Code

Откройте `claude` в папке курса и попросите: «объясни разницу между `??`
и `||` на трёх примерах из тестов». Каждый пример, который он даст,
запустите сами через `node -e "…"` и убедитесь, что вывод совпал
с объяснением. Если не совпал — это и есть находка.
