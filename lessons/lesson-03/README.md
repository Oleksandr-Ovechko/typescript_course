## Зачем этот урок

Открываем любой тест в `wl-e2e` и видим примерно это:

```ts
import { test } from '@playwright/test';
import { createNewLeadCaptureSkinAndWaitForLoad } from './C154005.helpers';

test.describe('[C154005][Lead Capture] Verify Form Settings ...', () => {
  test.beforeEach(async ({ page }, testInfo) => {
    await createNewLeadCaptureSkinAndWaitForLoad(page, `C154005_${testInfo.retry}`);
  });
});
```

Шесть строк — и ни одна конструкция из них пока не разбиралась. К концу занятия
этот файл должен читаться целиком, без белых пятен.

## Словарь терминов

Восемь новых слов. Все встретятся на уроке — можно прочитать заранее, можно
подсматривать по ходу.

### Стрелочная функция

*arrow function*

Короткая запись функции: параметры, стрелка `=>`, тело. Если тело — одно выражение,
фигурные скобки и `return` не нужны.

```ts
const double = (n: number): number => n * 2;
```

Отличается от `function` не только формой: стрелочная — это обычная переменная,
поэтому вызвать её выше по файлу, чем она объявлена, нельзя.

### Колбэк

*callback*

Функция, которую передают **в другую функцию как аргумент**, чтобы та вызвала её
сама, когда посчитает нужным. Вы её пишете, но не вызываете — вызывает принимающая
сторона.

```ts
[1, 2, 3].map((n) => n * 2);   // (n) => n * 2 — колбэк, его вызовет map
```

В тесте `test.describe('имя', () => { ... })` второй аргумент — тоже колбэк.

### Модуль

Файл, который что-то отдаёт наружу или берёт снаружи. Всё, что объявлено внутри
модуля, по умолчанию видно только ему — соседние файлы об этом не знают.

### Экспорт

*export*

Пометка «это имя можно брать из моего файла».

```ts
export const DEFAULT_TIMEOUT = 15000;
export function buildProfileUrl(uid: string): string { ... }
```

Без `export` имя остаётся внутренним.

### Импорт

*import*

Взять имя из другого файла.

```ts
import { DEFAULT_TIMEOUT, buildProfileUrl } from './wl-helpers';
```

Путь с точки (`./`, `../`) означает «наш файл в проекте», без точки
(`@playwright/test`) — «пакет из библиотеки».

### Деструктуризация

*destructuring*

Способ вытащить поля объекта или элементы массива в отдельные переменные одной
строкой.

```ts
const { who, host } = session;   // из объекта — по имени поля
const [first, second] = sizes;   // из массива — по позиции
```

Работает и в параметрах функции — именно так устроено `async ({ page }) => {...}`
в каждом тесте.

### Спред

*spread*, `...`

«Разложить содержимое сюда». Делает **новую** копию, а не ссылку на старый объект.

```ts
const copy = { ...base };                      // копия
const changed = { ...base, embedMode: 'inline' }; // копия с изменением
const all = [...smoke, 'regression'];          // склейка массивов
```

Копия поверхностная: вложенные объекты остаются общими с оригиналом.

### Фикстура

*fixture*

Готовый объект, который Playwright создаёт для теста сам и передаёт в колбэк:
`page` — вкладка браузера, есть ещё `browser`, `context` и другие. В фигурных
скобках просят только то, что нужно этому тесту.

```ts
test('название', async ({ page }) => { ... });
```

## Заодно всплывёт

Эти две вещи разберём вскользь — полностью на следующем уроке.

**`async` и `await`.** `await` перед вызовом — «дождись, пока это закончится,
и дай результат». `async` перед функцией — «внутри есть `await`, поэтому саму
функцию тоже надо ждать». Почти всё в Playwright требует ожидания, отсюда `await`
почти в каждой строке.
