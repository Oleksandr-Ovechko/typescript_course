# Примеры двенадцатого урока

Всё, что было на экране, — в готовом виде и с объяснениями. Файлы `.sh`
собирают свою песочницу в `/tmp/wl-pw-examples/`, запускают Playwright
и по ходу рассказывают, что произошло. Последний файл — обычный
TypeScript, без Playwright.

```bash
bash lessons/lesson-12/examples/02-lazy-and-autowait.sh   # запустить любой .sh
cd /tmp/wl-pw-examples/lazy-and-autowait                  # песочница остаётся — ковыряйте
node lessons/lesson-12/examples/08-prototypes.ts          # прототипы
```

Ничего за пределами `/tmp` скрипты не трогают. Объяснение каждой темы —
в [конспекте урока](../README.md).

## Что нужно, чтобы запустить

Только установленный `wl-e2e`: Playwright берётся из его `node_modules`
симлинком — та же версия, что в проекте. Стенд и интернет не нужны.

Если `wl-e2e` лежит не в `~/work/wl-e2e`, укажите путь:

```bash
WL_E2E=/путь/к/wl-e2e bash lessons/lesson-12/examples/01-modes-and-pause.sh
```

Каждый прогон поднимает свой сервер на порту **4174** и гасит его после.
Если скрипт говорит, что порт занят, — где-то завис прошлый прогон или
открыт UI-режим: `fuser -k 4174/tcp`.

## Порядок чтения

**02 → 03 → 04 → 05** — одна линия: локатор ищет заново → кто ждёт,
а кто нет → что если нашлось несколько → как выбрать точнее. 05 кончается
алгоритмом, который собирает всё вместе. **06** — отдельная причина
«нашёл 0».

**07 → 08** — вторая половина урока: где лежат методы.

**01** можно читать отдельно — но режимы с окном открывайте сами, по
командам из него: сценарий их не запускает.

## Чего ждать от вывода

- **Время в скобках гуляет** от прогона к прогону. Порядок строк тоже:
  номера у тестов раздаются по мере завершения.
- **`04` и `05` печатают `(код возврата: 1)`** — так задумано: там есть
  тесты, которые падают, чтобы показать ошибку. Сами скрипты доходят
  до конца.
- **`07`** печатает имена `_Locator` и `_Page` — с подчёркиванием, так они
  называются внутри собранного пакета Playwright.

Весь набор подряд идёт около минуты:

```bash
for f in lessons/lesson-12/examples/0*.sh; do bash "$f"; done
node lessons/lesson-12/examples/08-prototypes.ts
```
