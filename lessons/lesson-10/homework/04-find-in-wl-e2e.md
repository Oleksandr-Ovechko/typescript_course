# Задание 4 · Найти в `wl-e2e` три конструкции урока

Кода писать не нужно. Нужно найти в проекте три места, дать ссылку `файл:строка`
и ответить на один вопрос про каждое: **что было бы, если конструкцию заменить
на соседнюю по смыслу**. Ответ «сломается» не принимается — нужно, *как*
именно и *когда* это стало бы видно: при `tsc`, при запуске или только
на staging через неделю.

Ищем на `autonomous-test-gen-experiment`, где вы работаете. Для каждой
найденной ссылки проверьте, есть ли этот файл на `draft`, — это то, что
уезжает в продукт:

```bash
cd ~/work/wl-e2e
git fetch origin
git cat-file -e origin/draft:<путь> && echo "на draft есть" || echo "на draft нет"
```

## 1. Цикл-ретрай с потолком

`for` со счётчиком, который повторяет действие не больше N раз и выходит
по `break`, как только получилось. Их тысячи: на рабочей ветке около
3 800 одних только `for (let attempt = 0; attempt < …`, на `draft` — около 1 150.

```bash
git grep -n 'for (let attempt = 0; attempt <' -- 'helpers/**/*.ts' | head
```

Пример с урока — `helpers/monolith/client-profile/add-relationship-page.ts:36` —
**не берите**, найдите свой.

**Вопрос.** Замените заголовок на `while (true)` и оставьте тот же `break`.
Что произойдёт в тот день, когда условие выхода не выполнится ни разу? Чем
такое падение отличается от падения исходного цикла — что будет в отчёте
и сколько времени пройдёт? Какое правило проекта это запрещает (найдите его
номер в `RULES.md`)?

## 2. `Array.from` над DOM-коллекцией

Внутри `page.evaluate` / `waitForFunction`: `Array.from(…querySelectorAll(…))`
или `Array.from(select.options)`. На рабочей ветке таких около 1 200 и 590,
на `draft` — около 370 и 170.

```bash
git grep -nE 'Array\.from\([a-zA-Z_.]*(querySelectorAll|\.options\))' -- 'helpers/**/*.ts' | head
```

**Вопрос.** Замените `Array.from(x)` на спред `[...x]`. В браузере это
работает — коллекция итерируемая. А что скажет `tsc`? Проверьте сами, не
по памяти: скопируйте строку в файл внутри `projects/monolith/`, запустите
проверку типов только на нём и запишите код ошибки.

```bash
cd ~/work/wl-e2e/projects/monolith
# положите строку в probe.ts, затем:
echo '{"extends": "./tsconfig.json", "include": ["probe.ts"]}' > probe-tsconfig.json
../../node_modules/.bin/tsc --noEmit -p probe-tsconfig.json
rm probe.ts probe-tsconfig.json
```

Объясните, **откуда** берётся ошибка: посмотрите `"lib"` в корневом
`tsconfig.json` проекта и сравните с тем, что было сказано на уроке про
`Symbol.iterator`. Почему `Array.from` при этом проходит? (Подсказка: вспомните,
какие **две** вещи он умеет принимать.)

И последнее: откройте тот же `probe.ts` в VS Code, **до** того как удалить.
Спред подчёркнут красным? Объясните расхождение между редактором и `tsc`.
(Подсказка: `Ctrl+Shift+P` → «TypeScript: Select TypeScript Version» —
посмотрите, какая версия выбрана сейчас и какая стоит в проекте.)

## 3. `for await`

Все места, где он есть, читают скачанный файл по кускам. На рабочей ветке
их **семь**, на `draft` — **три**.

```bash
git grep -n 'for await' -- 'projects/**/*.ts' 'helpers/**/*.ts'
```

**Вопрос.** Уберите `await` и оставьте просто `for (const chunk of stream)`.
Что скажет `tsc`, и что случилось бы при запуске, если бы проверки типов
не было? Посмотрите, что делают с кусками **после** цикла: попадает ли в итоге
файл в память целиком? Если да — меняет ли это что-нибудь в том, зачем вообще
читать его потоком?
