# Примеры восьмого урока

Всё, что было на экране, — в готовом виде и с объяснениями. Каждый файл
исполняемый: он заводит свою песочницу в `/tmp/wl-git-examples/`, выполняет
команды и по ходу рассказывает, что произошло.

```bash
bash lessons/lesson-08/examples/01-three-trees.sh   # запустить любой файл
cd /tmp/wl-git-examples/l8-three-trees              # песочница остаётся — ковыряйте
```

Ничего за пределами `/tmp` скрипты не трогают: ваш рабочий репозиторий
в безопасности. Объяснение каждой темы — в [конспекте урока](../README.md).

## Порядок чтения

**01 → 02 → 03** читаются подряд: во втором нет ничего, что не выводилось бы
из первого («индекс» и «кусок дифа»), в третьем — ничего, что не выводилось бы
из второго. Если в 03 что-то не сходится, вернитесь в 01.

**05, 06, 07** — прикладные, их можно брать по одному, когда понадобится.
Из них самый ценный для работы — `bisect` в 05: он находит сломавший коммит
за десять проверок вместо двадцати прогонов.

**08** — справочник. Если непонятны сами команды терминала (`>`, `|`, `&&`),
начинать нужно с него, а не с 01.
