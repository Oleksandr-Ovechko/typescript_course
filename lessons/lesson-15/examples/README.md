# Примеры пятнадцатого урока

Весь код, который был на экране, — в готовом виде и с комментариями.
Читать сверху вниз, запускать каждый файл и сверять вывод с тем, что ожидали.
Объяснение каждой темы — в [конспекте урока](../README.md).

Шаблоны удобно повторять на [regex101.com](https://regex101.com/): слева
выбрать flavor **ECMAScript (JavaScript)**, тестовые строки — каждую на своей
строке и флаг `m`, чтобы `^` и `$` срабатывали у каждой.

```bash
node lessons/lesson-15/examples/01-pattern-basics.ts   # запустить любой файл
yarn typecheck                                         # проверить типы всех примеров
```

## Порядок чтения

**01 → 02 → 03 → 04** — каждый файл опирается на предыдущие. Там, где
строка проекта забегает вперёд (функция времени в 02), в комментарии
сказано, в каком файле объяснение.

Регулярки в локаторах Playwright запустить через `node` нельзя — они
разобраны в конспекте: [Регулярка в локаторе](../README.md#регулярка-в-локаторе).
