## О чём урок

Вы просили разобрать ООП — объектно-ориентированное программирование.
На прошлом занятии мы выяснили, **как** устроен класс. Теперь — **зачем**
он нужен и что стоит за четырьмя словами, которыми ООП обычно описывают:
инкапсуляция, наследование, полиморфизм, абстракция.

Через всё занятие пройдёт один вопрос. Playwright написан классами:
`page`, локаторы, `expect` — объекты с методами. А наши хелперы — больше
полутора тысяч **функций** в сотне файлов `…-page.ts`, и классов среди них
нет. Почему? К концу занятия ответ соберётся сам.

## Определения

**Объектно-ориентированное программирование (ООП)** — методология
программирования, основанная на представлении программы в виде
совокупности **объектов**, каждый из которых является экземпляром
определённого **класса**, а классы образуют **иерархию наследования**
(определение Гради Буча).

Четыре принципа, на которых оно стоит:

| Принцип | Формально |
|---|---|
| **Инкапсуляция** | объединение данных и методов, работающих с ними, в одном объекте и сокрытие его внутреннего устройства |
| **Наследование** | описание нового класса на основе существующего: наследник получает свойства и методы родителя и добавляет свои |
| **Полиморфизм** | объекты разных классов отвечают на один и тот же вызов по-своему; код работает с ними через общий интерфейс |
| **Абстракция** | выделение существенных характеристик объекта и отбрасывание несущественных: важно, что объект умеет, а не как он устроен |

Сейчас это формулировки из учебника. К концу занятия за каждой будет
стоять код.

В классе-наследнике переписали только `mark` — теперь он возвращает

## Словарь терминов

Семь новых слов. На занятии они появятся в этом же порядке.

| Термин | Что значит |
|--------|------------|
| **инкапсуляция** (encapsulation) | данные и методы, которые с ними работают, собраны в одном объекте, а внутреннее устройство скрыто: менять данные можно только его собственными методами |
| **геттер** (getter) | функция, которая вызывается, когда свойство читают. Пишется `get имя() { … }`, читается без скобок: `obj.имя` |
| **сеттер** (setter) | функция, которая вызывается, когда свойству присваивают. Пишется `set имя(значение) { … }`, вызывается знаком `=` |
| **наследование** (inheritance) | новый класс описывается на основе существующего: `class B extends A`. Наследник получает поля и методы родителя и дописывает свои |
| **переопределение** (override) | метод с тем же именем в классе-наследнике. Вызывается он, а не родительский |
| **полиморфизм** (polymorphism) | объекты разных классов отвечают на один и тот же вызов по-своему |
| **абстракция** (abstraction) | выделить в объекте существенное и отбросить остальное: важно, что он умеет, а не как устроен |

Слова с прошлого занятия понадобятся с первой минуты:

| Термин | Что значит |
|--------|------------|
| **класс** (class) | запись, которая в одном месте описывает конструктор и методы прототипа |
| **экземпляр** (instance) | объект, созданный через `new` |
| **поле класса** (class field) | данные экземпляра, объявленные в теле класса. Заводится заново для каждого экземпляра |
| **модификатор доступа** | слово перед полем или методом (`private`), которое говорит TypeScript, откуда к нему можно обращаться |
| **прототип** (prototype) | объект, в котором JavaScript ищет свойство, если его нет в самом объекте |
