# Примеры четырнадцатого урока

Весь код, который был на экране, — в готовом виде и с комментариями.
Читать сверху вниз, запускать каждый файл и сверять вывод с тем, что ожидали.
Объяснение каждой темы — в [конспекте урока](../README.md).

```bash
node lessons/lesson-14/examples/01-encapsulation.ts   # запустить любой файл
yarn typecheck                                        # проверить типы всех примеров
```

## Порядок чтения

**01 → 02 → 03** — три принципа по очереди, каждый файл опирается на
предыдущий. В 03 повторяются классы из 02 — чтобы файл можно было
запустить отдельно.

**04** — ответ на вопрос всего занятия: почему Playwright написан
классами, а наши хелперы — функциями. Читать последним.

## Строки с ❌

Код, который не должен компилироваться, закомментирован и помечен кодом
ошибки. Раскомментируйте строку под пометкой и запустите `yarn typecheck` —
увидите ровно эту ошибку. Все коды проверены скриптом.
